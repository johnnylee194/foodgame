# 美食英雄 (foodgame)

美食英雄是一个为“万元微创业”街头烧烤加盟项目量身定制的轻量级游戏化运营小程序 Demo。旨在通过“消费阶梯抽奖”与“碎片掉落合成”两大核心机制，化解顾客出餐高峰期的等位催单焦虑，并利用极低成本（10%营业额预算）锁定核心客群，提升门店复购率。

## 🚀 核心机制

- **阶梯抽奖系统**：每消费 100 元获取 1 次抽奖机会，利用极低概率的 666 元免单大奖制造门店轰动效应，配合高频低成本单品奖励拉动回流。
- **碎片掉落引擎**：植入碎片化消除类游戏，利用等餐的真空期掉落特定招牌大菜的碎片（如烤羊腿碎片 2/3），通过沉没成本心理刺激顾客后续主动组局、呼朋唤友再次光临。

## 🛠 技术栈

本阶段 Demo 基于 Web 端模拟小程序运行环境：
- **框架**: React 18 + Vite
- **语言**: TypeScript
- **样式**: TailwindCSS (暗黑霓虹夜市风格)
- **状态管理**: Zustand 
- **图标**: Lucide-react

## 📦 分阶段开发路线

- [x] **Phase 1**: 前端骨架搭建、全局 Mock 数据状态管理（资产盘、消费进度）、底部导航与背包 UI 基础实现。
- [ ] **Phase 2**: 阶梯抽奖系统、大转盘/盲盒交互及概率控制、资产入库流转逻辑。
- [ ] **Phase 3**: “串了个串”三消游戏引擎与碎片随机掉落控制机制。
- [ ] **Phase 4**: 碎片合成中心（满进度自动合成）、核销展示闭环（生成模拟核销二维码与后厨小票数据流）。
